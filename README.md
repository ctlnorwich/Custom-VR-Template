# Custom VR Template for starting off VR projects within Unity.

Feel free to use this template as a jumping off point for your projects. The template should be completely ready for development with Meta Quest headsets and comes with Unity learn assets provided for quick and easy prototyping.

### Setup:
In order to use the template you'll need to add it to your unity hub templates.
  - Close Unity Hub
  - Download (Code > Download ZIP) this repo
  - Navigate to your Unity Templates folder on your PC
   
    > This can be set from Unity Hub under Settings > Templates > Templates location
  
  - Paste the contents of this repo into your templates folder
  - Re-open Unity hub and create a new project. When selecting a template you should find this template under the 'Custom' page
